#  Sistema para PetShop

Um projeto desenvolvido em Java com foco na prática dos conceitos de **Programação Orientada a Objetos (POO)**. O sistema simula o gerenciamento e a rotina de atendimento de um Petshop.

---

##  Funcionalidades:

- [x] Cadastro de Pets com atributos de estado (nome, limpo/sujo).
- [x] Módulo de Banho com controle de consumo de insumos:
    - [x] Consumo de água por atendimento.
    - [x] Consumo de shampoo por atendimento.
    - [x] Verificação de capacidade máxima e abastecimento dos reservatórios.
- [ ] Novas rotinas de atendimento *(em desenvolvimento)*.

---

##  Tecnologias Utilizadas:

- **Java** (JDK 21)
- **IntelliJ IDEA**
- **Git & GitHub**

---

##  Como Executar o Projeto:

1. Clone este repositório no seu computador:
   ```bash
   git clone https://github.com/devLucasLira/Sistema-para-PetShop.git
   ```
2. Abra o projeto na sua IDE de preferência (recomendado: **IntelliJ IDEA**).
3. Localize o arquivo `src/Main.java`.
4. Execute o método `main` para rodar o sistema.
